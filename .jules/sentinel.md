## 2024-05-18 - Missing Explicit SSH Password Authentication Disable
**Vulnerability:** The NixOS OpenSSH configuration (`services.openssh.enable = true;`) lacked an explicit directive disabling password authentication (`services.openssh.settings.PasswordAuthentication = false;`), leaving the system reliant on defaults which may allow weak password-based access.
**Learning:** In NixOS, enabling a service like OpenSSH often inherits default settings that might be permissive. Relying on default configurations for critical security boundaries is risky if those defaults change or are misunderstood. This repository has a core security pattern of explicitly defining security boundaries and mechanisms.
**Prevention:** Always explicitly define critical security settings (like `PasswordAuthentication = false` or `PermitRootLogin = "no"`) in the NixOS configuration using the modern `services.openssh.settings` attribute set, rather than relying on assumed defaults. Ensure pre-provisioned keys are available before doing so to prevent lockout.
